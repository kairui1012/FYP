# Multilingual Educational Community Platform

## Project Title

Enhancing Learning Engagement through a Multilingual Educational Community Platform in Malaysia

## Project Overview

This project is a multilingual educational community platform designed for Malaysian students. The platform allows users to ask questions, share learning resources, reply to other users, and interact in an educational community environment.

The system supports three languages:

- English
- Bahasa Malaysia
- Mandarin / Chinese

The purpose of the platform is to help students overcome language barriers, improve access to learning support, and encourage student interaction through community-based learning.

## Project Aim

The aim of this project is to develop an educational website with a user-friendly interface and multilingual support. The platform allows users to seek help, share knowledge, and solve learning-related problems.

The platform also supports SDG 4: Quality Education by improving access to educational resources and academic support for Malaysian students.

## Project Objectives

1. To investigate the challenges and limitations of existing digital learning platforms in Malaysia.

2. To develop a multilingual, user-friendly, and interesting education community platform that allows users to access educational resources and ask questions easily.

3. To evaluate the system functionality in real-life learning scenarios and assess its effectiveness in improving access to educational resources and academic support.

## Target Users

The primary target users are Malaysian students and citizens who need an educational community platform to ask questions, share learning resources, and receive help from others.

## Main Problems Addressed

### 1. Language Barrier

Malaysia is a multilingual country. Many students are more comfortable learning in different languages such as English, Bahasa Malaysia, or Mandarin. Existing platforms may not fully support this multilingual environment.

### 2. Lack of Educational Community

Many students currently use informal platforms such as WhatsApp, Telegram, Facebook, or Reddit to ask academic questions. However, these platforms are not designed specifically for education and may contain distractions.

### 3. Low Learning Motivation and Interaction

Many digital education platforms focus mainly on content delivery or assignment management. They often lack interaction, motivation, and community engagement features.

## Project Inclusions

The project includes the development of a multilingual educational community platform that provides a user-friendly web-based interface for Malaysian students.

The platform allows users to:

- Learn anytime and anywhere
- Ask questions
- Reply to questions
- Share learning resources
- Use the website in English, Bahasa Malaysia, or Mandarin
- Interact with other users through likes, follows, leaderboards, and achievements

## Project Exclusions

The project does not include:

- Providing official educational content
- Mobile application development
- Integration with external learning management systems
- Evaluation of actual academic performance improvement
- Advanced cybersecurity features beyond basic login protection
- Long-term platform maintenance and updates

## Functional Requirements

## 1. User Registration and Login ☑️

The platform must provide login and registration features.

Users should be able to:

- Register an account
- Log in to the platform
- Log out from the platform
- Access platform features after authentication

This function allows users to create their own identity and participate in the educational community.

## 2. Multilingual Language Switching ☑️

The platform must include a language-switching feature.

Supported languages:

- English
- Bahasa Malaysia
- Mandarin / Chinese

Users should be able to change the platform language according to their preference.

The multilingual function should be available across the website interface to support Malaysia’s multilingual learning environment.

## 3. View Posts ☑️

Users must be able to view posts created by other users.

Posts allow users to:

- Read questions from other students
- View shared learning resources
- Browse educational discussions
- Learn from other users’ answers and explanations

## 4. Create Posts / Ask Questions ☑️

Users must be able to create posts to ask questions or share learning-related information.

A post should include:

- Title
- Content / description
- Category
- Uploaded files, if needed
- Images, if needed
- Documents, if needed

This feature allows students to seek help when they face learning difficulties.

## 5. Reply to Questions ☑️

Users must be able to reply to posts created by others.

Replies allow users to:

- Answer questions
- Explain solutions
- Share opinions
- Help other students understand learning content

This supports peer-to-peer learning inside the platform.

## 6. Upload and Share Study Resources ☑️

Users must be able to upload and share study resources with other users.

Supported resource types mentioned in the document include:

- PDF files
- Images
- Documents

This feature allows students to share useful academic materials and learning references.

## 7. Post Category Function ☑️

Posts must include a category function.

The category function helps organize topics and makes it easier for users to find learning content.

Examples of possible educational categories:

- Mathematics
- Science
- English
- Bahasa Malaysia
- Mandarin
- History
- Geography
- Computer Science

The exact categories can be adjusted based on the system design.

## 8. User-Friendly Interface ☑️

The platform must provide a user-friendly interface.

The interface should be:

- Clear
- Easy to navigate
- Simple to understand
- Suitable for students
- Accessible to users from different language backgrounds

A user-friendly interface is important because the project focuses on helping students access educational support easily.

## 9. Like Function ☑️

The platform must include a like function.

Users should be able to like:

- Posts
- Replies / answers

The like function helps show which content is useful or helpful.

It also supports interaction between users and encourages students to contribute better answers.

## 10. Follow Function ☑️

The platform must include a following function.

Users should be able to follow other users.

This allows users to:

- Keep track of users they are interested in
- View updates from followed users
- Build learning connections inside the community

## 11. Leaderboard Function ☑️

The platform must include a leaderboard.

The leaderboard can show user rankings based on learning activity or contribution.

The leaderboard supports motivation by allowing users to see their progress and compare their contribution with others.

## 12. Achievement Function ☑️

The platform must include an achievement function.

Users can earn achievements when they perform learning-related activities.

Examples of achievement-related activities from the document include:

- Receiving likes
- Gaining followers
- Answering questions
- Contributing to the community

Achievements can be displayed on the user profile to give users a sense of progress and motivation.

## 13. Bookmark / Save Post Function ☑️

Users must be able to save or bookmark posts for future reference.

This allows users to:

- Save useful posts
- Revisit learning materials later
- Organize important educational content
- Continue learning from saved resources

## 14. Search Function ☑️

The platform must include a search function.

Users should be able to search for content on the platform.

The search function helps users find:

- Posts
- Questions
- Learning resources
- Educational content

This supports the project goal of helping users access educational information more efficiently.

## 15. User Profile

The platform should include a user profile because the document mentions that likes, followers, and achievements can be displayed on the user profile.

The profile can show:

- User information
- Number of followers
- Likes received
- Achievements
- User contributions

This helps users feel a sense of achievement when their contribution grows.

## 16. Anonymous / Custom Identity Support ☑️

The document mentions that students may be afraid to ask questions because of losing face in traditional classroom settings. Therefore, the platform allows users to use a customized profile and username, helping them ask questions using a fake or anonymous identity.

This function helps students ask questions more comfortably.
