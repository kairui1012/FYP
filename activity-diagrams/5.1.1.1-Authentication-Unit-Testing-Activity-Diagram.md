# Activity Diagram: Authentication Unit Testing Flow

## Diagram Name
**User Authentication & Authorization Flow Activity Diagram**

## Overview
This activity diagram illustrates the complete authentication flow including landing page access, registration, login (both standard and Google), and blocked user handling.

## Main Flow Breakdown

### 1. **Landing Page Entry Point**
- **Start**: User accesses application
- **Decision**: Check if user is logged in
  - **Yes** → Redirect to Home Page (LP-02)
  - **No** → Display Login Page (LP-01)
- **Action**: Display Register option (LP-03)

### 2. **Registration Flow Branch**
- **Start**: User clicks "Register"
- **Sequential Validations**:
  - Validate Name (RL-02) → If empty, show error → Return to form
  - Validate Email (RL-03) → If invalid format, show error → Return to form
  - Check Email Uniqueness (RL-04) → If exists, show "already taken" error → Return to form
  - Validate Password (RL-05) → If weak, show error → Return to form
  - Validate Password Confirmation (RL-06) → If mismatch, show error → Return to form
  - **Success**: Create new account (RL-07) → Auto-login → Redirect to Home Page

### 3. **Standard Login Flow Branch**
- **Start**: User enters credentials (email + password)
- **Decision**: Email exists in system?
  - **No** → Reject login (RL-11) → Show error message
  - **Yes** → Check password
    - **Wrong password** → Reject login (RL-12) → Show error message
    - **Correct password** → Continue to next check
- **Decision**: Check user role
  - **Admin** → Redirect to Admin Users Page (RL-10)
  - **Student** → Redirect to Home Page (RL-09)
- **Decision**: Check login attempts
  - **>5 attempts in 1 minute** → Block login temporarily (RL-13) → Show blocking message

### 4. **Google Login Flow Branch**
- **Start**: User clicks "Google Login Button" (GL-01)
- **Action**: Navigate to Google sign-in page
- **Decision**: User action on Google page?
  - **Cancel** → Navigate back to login page with error message (GL-02)
  - **Complete sign-in** → Retrieve Google account data → Check if has email
    - **No email** → Reject login (GL-06)
    - **Has email** → Continue
- **Decision**: Check account status
  - **Google account is blocked** → Reject login with blocked error (GL-07 & BU-02)
  - **Not blocked** → Continue
- **Decision**: Check if account exists
  - **Email matches existing account** → Link account if not already linked (GL-05)
  - **New email** → Create new account (GL-04)
  - **Both cases** → Check user role
    - **Admin** → Redirect to Admin Users Page (GL-08)
    - **Student** → Redirect to Home Page (GL-03, GL-04, GL-05)

### 5. **Blocked User Handling Flow**
- **Scenario 1**: Standard Login with blocked account (BU-01)
  - Email matches blocked user → Reject login
- **Scenario 2**: Google Login with blocked account (BU-02, BU-03)
  - Google email belongs to blocked user → Reject login with blocked error
- **Scenario 3**: Already logged in, then account blocked (BU-04)
  - User attempts to visit any page → Auto-logout → Redirect to login page
- **Scenario 4**: Normal user accessing protected page (BU-05)
  - User not blocked → Page loads normally
- **Scenario 5**: Admin blocking another admin (BU-06)
  - Target user is admin → Prevent blocking → Show error message
- **Scenario 6**: Blocked user resets password (BU-07)
  - New password doesn't matter → Login still rejected → Stay blocked

## Key Decision Points (Parallel/Synchronization Nodes)
1. **Login Status Check** - Split into logged in/not logged in paths
2. **Authentication Method Selection** - Split into Standard Login vs Google Login
3. **Validation Chain** - Sequential validation gates during registration
4. **User Status Verification** - Check if user is blocked or role-based
5. **Account Linking Logic** - Determine if new account creation or existing account linking

## End Points (Terminal Nodes)
1. **Home Page** - Successful student login
2. **Admin Users Page** - Successful admin login
3. **Login Page with Error** - Failed authentication or blocked user
4. **Temporary Block** - Rate limit exceeded
